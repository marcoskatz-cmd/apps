Portal de Sistemas

Acceso centralizado a los sistemas internos. Cada sistema conserva su propio ingreso.

Cómo agregar o editar un sistema
  1. Abrí este archivo con cualquier editor de texto y buscá el array SISTEMAS al inicio del <script>.
  2. Copiá un bloque existente y editá los campos. El orden de las categorías lo define CATEGORIAS.
  3. Para habilitar un sistema pendiente, completá url con la dirección real. Si url queda en null, la tarjeta se muestra deshabilitada y no es clickeable.
  4. Guardá y hacé git push. No hay build ni backend: el archivo se publica tal cual.
// Un sistema = un objeto del array
{
  nombre: 'Combustible',
  categoria: 'Flota y Mantenimiento',  // debe existir en CATEGORIAS
  descripcion: 'Carga y control de combustible.',
  login: 'A confirmar',                 // se muestra como tag
  url: null                            // null = tarjeta deshabilitada
}
